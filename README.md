Project Title

Lost & Found System**


Project Description

The Lost & Found System is a web-based application designed to help users report, search for, and claim lost or found items. It provides an organized platform where users can submit item details, upload images, and track the status of reports, making it easier to reunite owners with their belongings.

Features

User Registration and Login
Report Lost Items
Report Found Items
Search Lost and Found Items
Upload Item Images
View Item Details
Manage Lost and Found Reports
Admin Dashboard
Update Item Status (Lost, Found, Claimed)



Technologies Used

 HTML
 CSS
 PHP
 MySQL
 XAMPP


How to Run

1. Install XAMPP on your computer.
2. Copy the project folder into the `htdocs` directory.
3. Start the Apache and MySQL services in XAMPP.
4. Import the project's database into phpMyAdmin.
5. Open your web browser and go to `http://localhost/your-project-folder`.
6. Log in or register to start using the system.
